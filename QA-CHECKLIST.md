# WEBSENSIAL — QA CHECKLIST

Gunakan checklist ini setelah perubahan. Tandai hanya item yang benar-benar diperiksa.

## 1. Referensi Visual
- [ ] Gambar di `public/reference/` dan aset terkait sudah dibuka/diperiksa.
- [ ] Layout aktual dibandingkan dengan referensi.
- [ ] Hero memiliki proporsi, hierarki, dan alignment yang tepat.
- [ ] Dashboard, smartphone, dan objek dekoratif tidak saling menutupi.
- [ ] Tidak ada bentuk 3D atau elemen yang terpotong tanpa sengaja.
- [ ] Logo resmi digunakan tanpa perubahan.
- [ ] Portfolio memiliki variasi visual yang relevan.
- [ ] Warna, tipografi, spacing, border, dan shadow konsisten.

## 2. Halaman dan Konten
- [ ] Beranda.
- [ ] Layanan.
- [ ] Portfolio.
- [ ] Marketplace/template.
- [ ] Detail produk.
- [ ] Demo Lab.
- [ ] CTA, kontak, atau waitlist bila ada.
- [ ] Footer.

Tandai hanya halaman yang memang ada dalam project dan ruang lingkup tugas.

## 3. Fungsi
- [ ] Navigasi bekerja.
- [ ] Semua CTA mengarah ke tujuan yang benar.
- [ ] Form memiliki validasi dan status yang sesuai.
- [ ] Filter dan pencarian bekerja jika ditampilkan.
- [ ] Preview sesuai dengan produk.
- [ ] Tidak ada notifikasi sukses palsu.
- [ ] Tidak ada link placeholder yang terlihat seperti fungsi aktif.

## 4. Bahasa
- [ ] Bahasa Indonesia lengkap.
- [ ] Bahasa Inggris lengkap.
- [ ] Pergantian bahasa mempertahankan halaman yang relevan.
- [ ] Tidak ada string yang tertinggal dalam bahasa yang salah.

## 5. Responsivitas dan Aksesibilitas
- [ ] Desktop.
- [ ] Tablet.
- [ ] Mobile.
- [ ] Tidak ada horizontal overflow.
- [ ] Keyboard focus terlihat.
- [ ] Tombol dan link dapat diakses dengan keyboard.
- [ ] Kontras teks memadai.
- [ ] Alt text gambar bermakna.
- [ ] `prefers-reduced-motion` dihormati.

## 6. Kualitas Teknis
- [ ] Tidak ada error console baru yang belum dijelaskan.
- [ ] Lint dijalankan jika tersedia.
- [ ] Typecheck dijalankan jika tersedia.
- [ ] Build dijalankan.
- [ ] Smoke test route utama dijalankan.
- [ ] Dependency baru memang diperlukan.
- [ ] Tidak ada secret di frontend atau repository.
- [ ] Environment variables dan integrasi backend diperiksa jika relevan.

## 7. Verifikasi Visual
- [ ] Website dijalankan.
- [ ] Screenshot aktual diperiksa jika browser tersedia.
- [ ] Hasil dibandingkan dengan referensi.
- [ ] Perubahan yang belum diverifikasi disebutkan secara jujur.
